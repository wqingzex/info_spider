## 💻 GitHub 热门仓库

### [piggyham/openpi](https://github.com/piggyham/openpi) `VLA基础`
> 来源: **GitHub** | 日期: 2026-08-01 | 作者: piggyham | ⭐ 0

OpenPi - Physical Intelligence open source robotics project

📌 **一句话总结**

Physical Intelligence 官方发布的完整开源 VLA 体系（π₀/π₀-FAST/π₀.₅），基于流匹配和自回归架构，支持 10k+ 小时预训练模型与多平台微调，π₀.₅ 通过知识隔离实现业界最强开世界泛化能力。

🎯 **问题与动机**

- **问题**：现有开源 VLA 要么缺乏生产级代码支持、要么仅限单一机器人平台；业界 VLA 训练依赖私有数据，难以复现。同时，流匹配与自回归两种范式在相同数据量上的权衡未有统一方案。

- **Gap**：弥补了 VLA 从学术→实战的工程空白——提供官方维护的可微调基础模型、多平台适配示例（DROID/ALOHA/LIBERO）、数据标准化方案（LeRobot），以及从 JAX 到 PyTorch 的完整生态。π₀.₅ 的知识隔离技术则填补了"如何在有限数据下实现跨物体、跨环境泛化"的研究空白。

- **Why it matters**：让研究者和企业能用通用基础模型快速适配自有机器人，而不需从零开始收集数万小时数据；加速了具身 AI 从小样本（ALOHA）到多任务、开世界的演进路径。

💡 **核心贡献**

1. **三层次 VLA 架构**（π₀/FAST/0.5）：流匹配模型更稳定但推理慢（π₀），自回归模型速度快但需更好的行为分词（π₀-FAST），π₀.₅ 通过知识隔离融合两者优点

2. **知识隔离（Knowledge Insulation）**：在预训练层学习任务不可知的通用表示，避免过拟合少量微调数据，实现最强开世界泛化（π₀.₅ 在 LIBERO 达 SOTA）

3. **完整微调生态**：提供数据转换、规范化统计重载、FSDP 分布式训练、远程推理部署的全链路工具；JAX/PyTorch 双实现降低接入门槛

4. **多平台验证**：在 DROID（7 自由度机械臂）、ALOHA（双臂仿人形）、LIBERO（模拟环境 50+ 任务）实现端到端闭环，证明泛化性

📊 **效果**

- **LIBERO 基准**：π₀.₅ 在 LIBERO 50 任务套件达到当前业界最高性能（具体数值见论文，repo 未直接公布百分比，但论文对标前序工作）

- **DROID 0-shot**：π₀-FAST-DROID 在未见过的场景直接执行表格操作，证明泛化能力（定性验证，无 success rate 百分比）

- **ALOHA 任务**：毛巾折叠、食物解包、笔帽解开等示例任务有演示但无量化指标

- **推理性能**：流匹配推理需 RT-1 耗时的 ~3 倍（精度换速度），自回归 FAST 逼近 RT-1 推理速度

- **资源需求**：推理需 8GB（RTX 4090），LoRA 微调 22.5GB，完全微调 70GB+（通过 FSDP 可分散到多 GPU）

---

**总体评价**：这是具身智能领域最权威的开源 VLA 参考实现。其价值不在单个算法创新，而在于**完整的工程闭环**——从数据规范化→预训练→微调→部署的每一步都有官方代码支持。π₀.₅ 的知识隔离则代表了 VLA 范式的演进方向（少数据下的泛化）。对于要快速启动机器人项目的团队，这是目前最可信的"基础设施"。

### [Vishal3347/nora3b-vla-inference](https://github.com/Vishal3347/nora3b-vla-inference) `VLA基础`
> 来源: **GitHub** | 日期: 2026-08-01 | 作者: Vishal3347 | ⭐ 0

Developed a local inference pipeline for the NORA-3B Vision-Language-Action model on a 4GB GPU, integrating it with a MuJoCo simulator for closed-loop robot control. Benchmarked and optimized inferenc...

📌 **一句话总结**

通过4-bit量化与torch.compile等优化技术，实现NORA-3B VLA模型在4GB GPU上的高效本地推理，并集成MuJoCo完成闭环机器人控制。

🎯 **问题与动机**

- **问题**：VLA端到端学习虽然理论优雅，但模型部署困难。现有工作多聚焦训练算法，对资源受限硬件（边缘GPU）的推理成本关注不足；低端硬件上运行VLA推理时常面临显存溢出、延迟过高导致无法实时控制的窘境。

- **Gap**：VLA研究与工程部署的鸿沟。社区缺少针对量化VLA推理的系统优化方案；对推理延迟、内存占用、吞吐量三角权衡的深入分析文献有限。

- **Why it matters**：机器人应用多运行在4-8GB的嵌入式GPU上。若VLA仅能在高端硬件推理，实际部署价值受限。本项目填补了"VLA→可用"的工程鸿沟。

💡 **核心贡献**

1. **低资源推理管道**：为NORA-3B设计了可在4GB显存内稳定运行的端到端推理系统，突破了VLA模型在边缘硬件上的可部署性瓶颈。

2. **多层次优化栈**：组合4-bit量化（减少模型大小）+ torch.compile（编译优化）+ 动态batch处理，形成递进式的优化方案，而非单一技术。

3. **闭环机器人集成**：连接视觉感知→VLA推理→MuJoCo动作执行，验证了优化后的VLA在模拟器中的闭环控制可行性。

4. **性能剖析工具链**：用PyTorch Profiler等量化分析延迟、显存、算力的分布，为后续优化指明方向。

📊 **效果**

项目未提供公开的定量对标结果（FPS、延迟ms级、准确率对比）。强度为系统工程验证：证明了NORA-3B在4GB GPU上可推理 + 支持闭环仿真，但缺乏与基线方法的量化对比（如原始精度推理、其他量化方案）。
