## 💻 GitHub 热门仓库

### [shihao1895/MemoryVLA](https://github.com/shihao1895/MemoryVLA) `VLA基础`
> 来源: **GitHub** | 日期: 2026-06-08 | 作者: shihao1895 | ⭐ 263

[ICLR 2026] Code of "MemoryVLA: Perceptual-Cognitive Memory in Vision-Language-Action Models for Robotic Manipulation"

**问题**: 现有VLA模型在机器人操作任务中缺乏持久性记忆机制：感知层面无法跨时间步积累物体状态信息，认知层面无法维护任务进度与上下文，导致在需要多步骤、长时序记忆的操作任务中决策质量显著下降。

**方法**: 提出MemoryVLA，核心机制是在VLA模型中引入感知-认知双层记忆（Perceptual-Cognitive Memory）：感知记忆存储历史视觉/状态特征，认知记忆维护任务级语义上下文，与现有VLA的本质区别在于赋予模型跨时间步的显式记忆读写能力。

**效果**: 论文被ICLR 2026接收，摘要为GitHub仓库描述，具体实验数值指标未披露。

**总结**: 核心创新是为VLA模型引入感知-认知双层记忆机制，解决了现有VLA在长时序机器人操作中无状态记忆导致的决策失效问题，该成果已被ICLR 2026接收。

Vision-Language-Action robotic manipulation using UR5, PyBullet, LeRobot, and SmolVLA for language-conditioned pick-and-lift tasks.

**问题**: 该仓库为工程实现项目而非研究论文，针对问题为：如何在真实物理仿真环境中将自然语言指令端到端地映射到机械臂的抓取动作，验证VLA模型（SmolVLA）在语言条件下的操作可行性。

**方法**: 基于LeRobot框架集成SmolVLA模型，以UR5机械臂+PyBullet物理仿真为执行环境，实现语言条件化的pick-and-lift任务；核心是将SmolVLA的语言-视觉-动作推理直接对接PyBullet仿真控制回路。

**效果**: 工程演示项目，原文未提供具体性能指标。

**总结**: 核心贡献是提供了SmolVLA+UR5+PyBullet的完整语言条件操作验证管线，验证了轻量级VLA模型在6自由度机械臂抓取任务中的端到端可行性。


### [hadi3112/humanoid-reinforcement-learning-simulator](https://github.com/hadi3112/humanoid-reinforcement-learning-simulator) `人形机器人`
> 来源: **GitHub** | 日期: 2026-06-07 | 作者: hadi3112 | ⭐ 0

Train a bipedal robot to walk using PPO (Proximal Policy Optimization) in a PyBullet physics simulation

**问题**: 双足机器人步行控制是经典高维连续控制难题，传统手工设计控制器需大量人工调参且泛化性差，如何在物理仿真中用强化学习自动习得稳定步态是核心挑战。

**方法**: 使用PPO（近端策略优化）算法在PyBullet物理仿真中训练双足机器人步行策略，基于标准的actor-critic架构，依靠仿真环境的物理反馈（关节力矩、平衡状态）作为奖励信号自动学习步态控制。

**效果**: 工程仿真项目，原文未提供具体性能指标（如步行速度、稳定性得分等）。

**总结**: 核心贡献是提供PPO+PyBullet双足步行训练环境，展示了强化学习在人形机器人运动控制仿真中的基础应用，但未涉及sim-to-real或语言条件控制。
